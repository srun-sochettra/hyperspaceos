# Security

HyperSpaceOS is a browser-based desktop demonstration. It is not a security boundary, private vault or substitute for the host operating system.

## Data and permissions

The application stores virtual files and desktop state in browser storage. Avoid secrets, credentials and irreplaceable documents. Clearing browser data can remove local work. Camera access is controlled through browser permissions; revoke permissions when no longer needed.

Weather and embedded browser pages involve external services. Local persistence does not mean every application is offline or makes no network requests. The command assistant can modify virtual files through rule-based commands.

## Reporting a concern

Do not publish secrets, personal data or exploit details in a public issue. Use a private reporting channel if the repository offers one. No dedicated security address, response deadline or supported-version policy is established here. If no private channel is available, request one without including sensitive details.

Useful reports identify the affected revision, browser, reproduction conditions, impact and a minimal non-sensitive example. Do not test against other people's data or systems.

This document is guidance, not a security audit or guarantee.
